# Model files

Place runtime model assets in this directory:

- **`tiles.pt`** — YOLO11 mahjong tile detection weights
- **`vosk-model-small-cn-0.22/`** — Vosk Chinese speech model for keyword listening

## Download Vosk model

```bash
curl -LO https://alphacephei.com/vosk/models/vosk-model-small-cn-0.22.zip
unzip vosk-model-small-cn-0.22.zip -d models/
```
